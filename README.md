## Install

Wally:

```toml
Dynamo = "elentium/dynamo@1.1.3"
```

Pesde:

```sh
pesde add elentium/dynamo
```

npm:

```sh
npm install @elentium/dynamo
```

Or copy `src/Dynamo.luau` into your project.
